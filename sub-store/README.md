# Sub-Store 节点筛选脚本

`operators/keep-core-premium-and-remote.js` 用于生成一个仅保留五国高倍率节点、同时保留其他地区节点的精简订阅。

`operators/filter-sort-by-region-and-quality.js` 是独立的 Script Operator：删除订阅说明项、规范重复节点名称，并按地区排序；同一地区内普通节点排在高倍率节点之前。除说明项和空名称节点外，所有节点都会保留；无法可靠识别国家的节点归为“其他”，避免误删供应商的特殊命名。

地区排序依次为：香港、台湾、美国、日本、新加坡、韩国、加拿大、阿根廷、英国、德国、法国、印度、马来西亚、土耳其、俄罗斯、乌克兰、意大利、巴基斯坦、埃及、澳大利亚、南非、其他。

高倍率标签与现有配置保持一致：严格匹配数值大于 `1x` 的倍率，例如 `1.01x`、`1.5x`、`2x`、`15x`。`0.1x`、`0.5x`、`1x`、`1.0x`、`1.00x` 不属于高倍率；`进阶IEPL`、`专线`、`原生`、`家宽`、`星链` 等线路类型词本身也不属于高倍率。

## 使用方式

1. 在 Sub-Store 建一个合集订阅，把机场订阅和私有节点源都加入其中。
2. 对这个合集添加 **脚本过滤（Script Filter）** 或 **脚本操作（Script Operator）**，将 `operators/filter-sort-by-region-and-quality.js` 的完整内容粘贴进去（或使用该文件可访问的脚本 URL）。
3. 预览输出：订阅说明项应消失，重复名称应带序号；节点应按地区排序，且同一地区的普通节点排在高倍率节点之前。
4. 将该 Sub-Store 输出订阅地址填入客户端或 OpenClash。`meta.ini` 仍负责策略组和分流规则；本脚本只负责节点筛选。

不要把它粘进“正则过滤”或“正则删除”。若曾使用旧版本脚本并看到“保留节点 0”，请删除旧操作后重新添加一个“脚本过滤”或“脚本操作”，再粘贴本文件的完整新内容。

不要在 Sub-Store 再添加全局 `0.1x`、`福利` 等正则删除规则；这会改变目前约定的筛选范围。
